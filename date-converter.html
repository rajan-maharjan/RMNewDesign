Developer Integration

Nepali Date REST API Documentation

Easily embed dynamic Nepali dates or convert calendars on your website or mobile application using Rajan Maharjan's public RESTful endpoints.

1. Available REST Endpoints

Both raw string outputs and structured JSON payloads are supported:

GET https://rajanmaharjan.com.np/getdate/

Returns today's Nepali Date as formatted HTML/string (e.g., वि.सं २०८३ असोज २६, सोमबार).

GET (JSON) https://rajanmaharjan.com.np/getdate/get-json.php?dateType=np

Returns structured JSON containing Nepali year, month, date, and day of week.

GET (Convert) https://rajanmaharjan.com.np/getdate/get-json.php?dateType=e2n&date=12-10-2026

Converts English date (DD-MM-YYYY) to Nepali BS date in JSON format.

2. Allowed Query Parameters

Parameter Allowed Values Description
dateType np, en, e2n, n2e Specifies output language or conversion mode.
dformat yyyy, mon, dd, day, adbs Isolates a single date component (e.g. year only, month only).
date DD-MM-YYYY format Required for e2n and n2e conversions.
